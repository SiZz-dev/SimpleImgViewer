# 기본 뷰어 UI

상단 URL 버튼과 `/viewer#url=<인코딩된 URL>`로 원격 파일을 열 수 있습니다. 서버가 허용된 주소에서 수신한 뒤 기존 비공개 미리보기/재생 API로 표시합니다. 원격 주소는 진입 시 브라우저 주소에서 제거하며 대화상자 취소 시 입력을 비웁니다. URL 기능이 꺼져 있으면 버튼을 비활성화합니다. [설정과 호출 예](REMOTE_URL_IMPORT.md)를 따릅니다.

최신 미지원 형식/구성·변환 실패의 고정 안내와 재시도 버튼 정책은 [PREVIEW_FAILURES.md](PREVIEW_FAILURES.md)를 참고합니다.

## 진입과 현재 동작

- /viewer: 한 줄 헤더·좌측 접이식 파일 목록·중앙 이미지·우측 도구, 푸터 없음.
- /viewer?sessionId=<UUID>: 소유자에게 허용된 기존 뷰어 세션 열기.
- /viewer?mediaId=<UUID>&mediaId=<UUID>: 등록된 파일들로 새 세션 생성 후 열기.
- 파일 열기: multipart 등록 → 세션 생성 → 선택 이미지 페이지 접수 → 페이지 상태 조회 → 검증된 PNG 표시.

다크가 기본이며 테마 버튼 하나로 라이트로 전환합니다.
테마만 localStorage에 저장합니다. 파일 ID·세션 ID·인증 정보·CSRF 토큰·이미지는 localStorage에 저장하지 않습니다.
뷰어 세션 ID는 새로고침을 위해 URL에 반영되며 인증이나 파일 접근 권한을 대체하지 않습니다.

구현: 확대/축소, 휠 기준점 확대, 화면 맞춤, 미리보기 100%, 드래그 이동,
90도 회전, 밝기 보기 조절/초기화, 2배 돋보기, 페이지 탐색, 반응형 패널.
단축키: +/− 확대/축소, 0 맞춤, 1 미리보기 100%, R 회전, L 돋보기, 좌/우 방향키 파일 이동.
입력 중에는 단축키가 파일/밝기 입력을 방해하지 않습니다.
100%는 미리보기 PNG 픽셀 기준입니다. 원본 고해상도/타일 확대는 후속 단계입니다.

페이지 이동은 필요한 페이지 한 개만 접수합니다. 상태 확인 간격은 1초부터 5초까지 늘리고,
2분을 넘기면 재확인 안내를 표시합니다. GET만으로 변환 작업을 접수하지 않습니다.
전체 페이지 수는 아직 확인되지 않아 —로 표시하며 존재하지 않는 페이지는 처리 실패 상태로 표시합니다.

## 도구와 미구현 범위

밝기·회전·확대·돋보기는 현재 보기에만 적용하며 원본을 변경하지 않습니다.
메모·스탬프·스탬프 업로드는 [편집 API](ANNOTATIONS_STAMPS.md)에 연결했습니다. 원본 좌표 확인과 파일 권한이 있는 페이지에서 클릭 생성·이동·크기 조절·텍스트 수정·삭제·복원을 지원합니다. 영역 자르기·정수 좌표 조정·PNG 사본 다운로드는 [자르기 API](CROP_EXPORT.md)에 연결했습니다. 저장된 메모·스탬프·현재 밝기/회전을 포함한 전체/선택 영역 PNG 합성 반출은 [편집 저장](EDITED_EXPORT.md)에 구현했습니다. 실행 취소는 후속입니다.
영상·음성은 [재생 API](PLAYBACK.md)에 연결했습니다. 검증된 FFmpeg 모듈 활성화 시 영상/음성 재생·탐색 막대·배속·음량·음소거·영상 전체 화면과 재생 정보 패널을 제공합니다.
이 기능들을 구현한 것처럼 동작하는 임시 버튼·재생기는 제공하지 않습니다.
미리보기의 원본 좌표 확인 여부/변환 행렬은 IMAGE_GEOMETRY.md를 따릅니다.

실제 UI 리소스는 src/main/resources/static/viewer 아래 HTML/CSS/ES module입니다.
외부 CDN·웹폰트·UI 라이브러리·새 런타임 의존성을 추가하지 않았습니다.
제품 화면에는 테스트용 샘플 파일이나 임시 인증 기능을 넣지 않았습니다.

## 인증·권한·CSRF

공개한 GET은 /viewer, /viewer/ 및 정확한 7개 CSS/JS 리소스뿐입니다.
빈 UI 셸에는 파일·인증 토큰이 없습니다.
업무시스템의 실제 SSO/로그인 공급자는 여전히 연결해야 합니다.
신뢰된 ViewerPrincipal이 없으면 UI는 로그인 필요 상태를 보여 주며 업로드를 비활성화합니다.
임의 헤더·사용자 ID·URL 토큰으로 로그인하는 기능은 없습니다.

GET /api/v1/viewer/bootstrap:
- 검증된 ViewerPrincipal 필수.
- features: 설치 정책과 실제 구현 범위를 교차한 UI 도구 사용 여부.
- csrf: headerName/token. Spring Security의 마스킹된 토큰을 응답하고 POST/PUT/DELETE에 해당 헤더로 전달.
- limits: maxFiles=100, maxUploadBytes=100MiB, maxPage=10000, 편집 수·메모 길이·스탬프 수·스탬프 업로드 바이트 상한.
- serverTime. 응답은 no-store.

파일 권한은 각 미디어/페이지/소스 API에서 계속 검사합니다.
UI도 세션을 20초마다 확인하고 만료·권한 상실 시 표시 이미지와 목록을 비웁니다.
다른 파일로 바꿀 때 진행 중인 요청을 취소하고, 늦게 완료된 이전 이미지가 화면을 덮어쓰지 않도록 검사합니다.
브라우저 복원 시에도 세션을 다시 확인합니다.
다운로드하는 소스는 동일 출처의 예상된 미디어/페이지 PNG 경로만 허용합니다.
파일명은 textContent로 표시하며 HTML로 삽입하지 않습니다.
CSP는 self와 이미지용 blob만 허용하고 inline script/eval/외부 CDN을 허용하지 않습니다.
Blob URL은 선택 변경·권한 상실·페이지 종료 때 해제합니다.

파일 수·파일당 크기를 UI에서도 확인하지만 최종 검증은 서버가 수행합니다.
여러 파일 중 일부 등록 실패 시 성공한 파일을 열고 실패 개수를 안내합니다.
세션 접수 자체가 실패한 경우 메모리에 성공한 ID를 보관해 재업로드 없이 재시도합니다.
미디어 등록 취소/삭제·조직별 저장 할당량은 여전히 후속 작업입니다.

## 썸네일·메모리와 속도 범위

목록은 최대 100개의 가벼운 항목을 표시하고 화면에 보이는 전용 썸네일만 지연 로드합니다.
화면 밖 썸네일의 이미지 참조를 제거합니다.
기본 256px의 전용 PNG를 사용하며 최대 512px 및 정확한 thumbnail URL/role을 검증합니다.
썸네일이 없거나 잘못된 경우 파일 아이콘을 표시하며 본문 미리보기를 목록용으로 다운로드하지 않습니다. THUMBNAILS.md를 참고하세요.
중앙 이미지 하나와 돋보기 캔버스를 유지합니다. 원본 파일 전체를 Base64 JSON으로 전송하지 않습니다.
보안 메타데이터·소스의 no-store 정책을 유지하며 브라우저의 공유 캐시에 권한을 위임하지 않습니다.

실제 업무 자료·동시 사용자 환경의 최초 표시 P95/메모리/네트워크 측정은 아직 수행하지 않았습니다.
이번 브라우저 검증은 UI 기능·레이아웃·요청 안전성 검사이며 부하 성능 인증이 아닙니다.

## 검증 실행

Java 검증(실제 재생 샘플 생성 포함):

~~~powershell
.\gradlew.bat test -Pimg2tileIntegration -PffmpegIntegration
~~~

브라우저 검증은 별도 개발용 Playwright와 Chromium 기반 브라우저를 사용합니다.
프로젝트 런타임에는 포함하지 않습니다. Playwright의 라이선스는 Apache-2.0입니다.

~~~powershell
$env:IMAGEGATE_NODE_MODULES = 'Playwright가 설치된 node_modules 절대 경로'
$env:IMAGEGATE_BROWSER = 'C:/Program Files/Google/Chrome/Application/chrome.exe'
node scripts/test-viewer.mjs
~~~

test-viewer.mjs는 루프백 HTTP 서버에 실제 UI 리소스와 동일 CSP를 제공하고,
브라우저 컨텍스트 내부에서만 합성 API 응답·합성 PNG를 사용합니다.
실제 SSO와 서버 변환의 종단간 시험을 대신하지 않습니다.
서버의 인증 경계·정적 리소스·기능 정책·실제 CSRF 토큰 사용은 ViewerUiApiTests로 별도 검사합니다.

브라우저 검사: 휠/버튼 확대·드래그·회전·밝기·돋보기, 테마 유지,
패널 접기 후 캔버스 폭, 페이지 이동, 빠른 선택의 이전 응답 취소,
파일명 XSS·외부 URL 거부·CSRF 헤더·권한 상실 화면 제거,
미인증 상태·기능 비활성 키보드 차단·모바일 단일 헤더.
캡처/결과는 build/ui-tests에 생성합니다. 설치 ZIP은 생성하지 않습니다.

현재 검증 결과는 개발 계획의 최신 검증 항목을 참고하세요. 메모·스탬프·자르기를 포함한 브라우저 시나리오 20개와 좌표/URL 계산을 검사하고 다크·라이트·모바일·편집 화면을 캡처합니다. 설치 ZIP은 생성하지 않습니다.

메모·스탬프의 서버 기록 기반 undo/redo 버튼·키보드, 입력/저장 중 보호와 충돌/응답 유실 재조회는 EDIT_HISTORY.md를 참고하세요. 기록은 파일/페이지별로 분리하고 화면 전환 뒤 늦은 응답을 무시합니다.
