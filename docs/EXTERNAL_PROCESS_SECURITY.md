# 외부 변환 프로세스 실행 경계

2026-10-23 보완. img2tile과 FFmpeg/FFprobe는 공통 BoundedProcessExecutor를 사용합니다. 이 문서는 현재 코드에서 검증한 경계와 OS에서 별도 적용해야 하는 제한을 구분합니다. native 모듈·DLL을 저장소에 추가하거나 새 의존성을 도입하지 않습니다. ImageMagick 실행/자동 우회는 추가하지 않습니다.

## 실행 파일과 작업 경로

- 실행 파일은 기존 일반 파일이며 작업 경로는 기존 디렉터리여야 합니다. 둘 다 정규화된 절대 canonical 경로만 허용합니다. 상대 경로, .. 정규화가 필요한 경로, symlink/Windows 정션 및 상위 경로 별칭을 거절합니다.
- NOFOLLOW 속성으로 유형/파일 식별자/생성 시각을 확인하고 시작 직전과 정상 종료 후 다시 비교합니다. 실행 파일은 크기·수정 시각도 비교합니다.
- 작업 폴더는 변환 결과 생성으로 크기/수정 시각이 정상 변경되므로 그 값 대신 디렉터리 정체성(fileKey/생성 시각)을 비교합니다. 동일 경로에 폴더를 바꾸는 경우도 실패합니다.
- 경로가 없으면 폴더/실행 파일을 생성하지 않습니다. 작업별 새 폴더 생성·입력/출력/리소스 검증은 기존 img2tile 어댑터·미리보기/재생 서비스의 책임입니다.
- 경로/변경/시작 실패는 고정 UNAVAILABLE 분류로 변환하며 원시 OS 오류·명령·경로를 예외 메시지에 포함하지 않습니다. 실제 시작한 프로세스는 실패 시에도 정리를 시도하고 실행 슬롯을 반환합니다.

경로 검사는 실행 파일의 암호학적 승인이나 DLL 전체 무결성을 대신하지 않습니다. FFmpeg의 기존 설치 해시/빌드 승인 및 img2tile의 모듈 식별과 별개로, 모듈 설치 경로/인접 DLL은 서비스 계정이 읽기/실행만 가능하도록 관리해야 합니다. 변경 가능한 native 디렉터리를 신뢰하지 않습니다. 경로 검사와 실제 열기/실행 사이의 OS 경쟁이나 속성을 의도적으로 복원하는 변경을 원자적으로 차단하는 기능은 아닙니다.

## 생성하는 환경 변수

부모 환경을 초기화한 뒤 아래 값만 생성합니다. 임의 추가 환경/부모 PATH 상속·보안 정책 비활성화 옵션은 제공하지 않습니다.

| 이름 | 값 |
| --- | --- |
| PATH | 실행 파일의 부모 디렉터리. Windows에서는 기존 SystemRoot/System32를 추가하며 OS 경로 구분자를 사용 |
| SystemRoot / WINDIR | Windows에서 서비스 시작 환경의 SystemRoot. 없거나 비어 있으면 실행 실패 |
| TEMP / TMP / TMPDIR / HOME | 해당 호출의 검증된 작업 디렉터리 |
| USERPROFILE | Windows에서 해당 호출의 작업 디렉터리 |

자격증명/임의 proxy·FFREPORT·JVM/로더 주입 변수 등을 부모에서 복사하지 않습니다. 회귀 테스트는 별도 부모 JVM에 합성 AWS 키·임의 비밀값·JAVA_TOOL_OPTIONS·FFREPORT·오염 PATH/홈/임시 경로를 넣고, 실제 자식 JVM에서 누락/대체를 확인합니다. 테스트는 실제 계정의 비밀 환경을 부모 fixture로 복사하지 않습니다.

HOME/USERPROFILE/TMPDIR 설정은 도구가 환경 변수 규약을 따를 때의 작업 경로 안내입니다. registry·OS API·절대 경로로 접근하는 파일/사용자 프로필/임시 위치를 차단하지 않습니다. stdin은 시작 즉시 닫아 상호작용을 기다리지 않게 하며 stdout/stderr는 통합하여 별도 가상 스레드에서 계속 소비합니다.

## 실행/출력/수명 제한

| 항목 | 현재 구현 |
| --- | --- |
| 셸 | 인자 배열 직접 실행. cmd/PowerShell/셸 문자열을 자동 조합하지 않음 |
| 명령 크기 | 실행 파일 포함 최대256인자, 문자열 길이 합계 최대32,768 UTF-16 단위, null/NUL 거절. 실제 OS 인자 인코딩/따옴표 길이 제한도 추가 적용됨 |
| 동시 실행 | 실행기 인스턴스별1~8. 슬롯을 기다리는 내부 큐 없음, 초과 BUSY |
| 시간 | 양수~5분, start 직전부터 기한 계산, 실행 중 약40ms마다 남은 시간/자식 확인, 초과 TIMEOUT |
| 출력 | stdout/stderr 계속 소비, 메모리 보관 최대8 KiB, 나머지 폐기 및 truncated 표시 |
| 종료/인터럽트 | 본 프로세스와 관찰한 자식 강제 종료 시도, 파이프 정리, 소유 슬롯 반환. 인터럽트 플래그 유지 |
| 정상 부모 종료 | 이전에 관찰한 자식도 종료 시도하여 남은 작업을 줄임 |

제한 시간은 native 시작 호출과 종료 정리의 강제 벽시계 상한까지 보증하지 않습니다. 기한/종료 처리 뒤에도 별도의 파이프 join/프로세스 wait 정리 시간이 필요합니다. JDK 원본 이미지 디코딩/후처리 전체 시간에 이 외부 실행 기한을 적용하지 않습니다.

이미지와 재생은 별도 실행기/큐를 사용하므로 각 동시성 값은 OS 전체 프로세스 수/CPU 하드 한도가 아닙니다. 샘플링 사이에 분리된 자식, 관찰되지 않은 재부모화 프로세스, OS에서 종료 거절된 프로세스까지 완전 추적·강제 통제하지 않습니다.

## 설치 옵션과 남은 OS 제한

config/imagegate.example.yml의 conversion.timeout/max-concurrent-jobs, playback.timeout/workers/queue-capacity 등 기존 설치 옵션을 유지합니다. 실제 config/imagegate.yml은 변경하지 않습니다. 경로/생성 환경/인자/출력 보관 정책은 고정 안전 경계이며 끄는 옵션이 없습니다.

| 영역 | 애플리케이션 수준 검증 | 별도 운영 인수 |
| --- | --- | --- |
| CPU/메모리 | 큐/동시 실행/시간·입력/결과 픽셀 제한, FFmpeg 고정 threads/max_alloc 레시피 | 전체 native RSS/CPU·프로세스/자식 수 하드 한도, JDK/도구 및 실패 시 종료 인수 |
| 디스크 | 작업별 비공개 폴더·결과 크기 검사, FFmpeg -fs와 후검증 | 실행 중 전체 산출물/임시 파일·디스크 여유/볼륨 quota·정리/보존 |
| 네트워크 | FFmpeg 고정 로컬 파일/format/protocol 레시피, 상속 proxy 환경 제거 | 별도 서비스 계정/방화벽·격리 환경에서 외부 통신 거절 확인 |
| 파일/자격증명 | 부모 환경 비밀값 전달 차단·경로 경계·검증 결과만 게시 | 같은 OS 계정으로 읽을 수 있는 다른 파일/registry/키 접근 제한·실제 ACL 인수 |
| native 모듈 | 고정 경로/일부 도구 승인·시작/종료 속성 대조 | 읽기 전용 EXE/DLL/리소스 설치·신뢰 해시/공급망·호환성/취약점 점검 |

FFmpeg max_alloc은 개별 할당 제한이지 전체 프로세스 메모리 한도가 아니며, img2tile 결과 크기는 주로 실행 후 검사입니다. 제한을 넘는 산출물을 게시하지 않는 것과 실행 중 디스크 사용을 하드 차단하는 것은 다릅니다. 이 구현을 OS 샌드박스나 네트워크/CPU/메모리 격리 완료로 분류하지 않습니다. 아직 검증하지 않은 OS 정책을 YAML에서 활성화됐다고 표시하지 않습니다.

## 검증

기존 무셸 인자 보존·출력 포화·TIMEOUT/슬롯 재사용·동시성 BUSY·관찰 자식 종료와 함께 다음을 확인합니다.

- 실제 자식 프로세스에서 부모의 합성 비밀값/JVM 옵션/FFREPORT 차단, PATH 재생성, 작업별 홈/임시 환경, cwd/상대 출력, stdin EOF.
- 잘못된 작업 경로/인자 상한/시작 실패 후 정상 후속 실행과 고정 오류.
- 인터럽트 플래그 보존/본 프로세스 종료/슬롯 회복, 정상 부모 종료 후 관찰 자식 정리.
- 정상 작업 산출물 생성은 허용하고 실행 파일 변경/작업 폴더 교체·Windows 정션은 거절.
- 실제 내부 img2tile·FFmpeg/FFprobe 및 기존 보안/캐시/재생 회귀.

fixture는 src/test에만 두고 실행 JAR에 포함하지 않습니다. 실제 업무 파일·사용자 앱/서비스·모듈 설치 파일을 변경하거나 운영 OS 정책을 자동 설정하지 않습니다. 브라우저 UI/운영 성능 재측정과 설치 ZIP 생성은 이 단계 범위가 아닙니다.

OS 하드 격리와 distributionReady=false는 별도 인수 상태로 유지.
