## 실행 순서와 통과 기준

아래 상태는 모두 **운영 미인수**입니다. 담당 역할은 배정 제안이며 실제 담당자·기한은 설치 조직에서 지정합니다. 해당 없음은 근거와 범위 승인이 필요하며, 미실행·일부 실행·실패는 통과로 집계하지 않습니다.
내부 모듈의 재현 폴더 구성과 외부 입력이 필요한 핵심 잔여 항목은 [NATIVE_MODULE_HANDOFF.md](NATIVE_MODULE_HANDOFF.md)에 정리했습니다. 진단 실행 완료를 오류 수정 또는 운영 승인으로 집계하지 않습니다.

## 샘플별 최소 확인표

A02의 로그인 방식은 미정이고 권한은 연계 시스템에서 전달받는 것으로 확인했습니다. 현재 확장 지점과 전달 자료 초안·공유 권한 검증은 [LINKED_AUTHORIZATION.md](LINKED_AUTHORIZATION.md)를 참고합니다. 합성 권한 fixture 통과를 실제 발급자/수신 채널·SSO 검증 완료로 바꾸지 않습니다.
스탬프·자르기·합성 반출·재생 캐시의 세부 행위/회수 검증은 [LINKED_ACTION_PERMISSIONS.md](LINKED_ACTION_PERMISSIONS.md)에 기록했습니다. 진행 중 전송의 중단이나 이미 전송한 바이트 회수를 인수한 결과는 아닙니다.

‘헤더 후보 분류’·‘미리보기 준비’·‘원본 좌표 편집’·‘고해상도 타일’·‘재생’은 별도 결과를 기록합니다. 다양한 형식을 목표로 하지만 현재 모든 변형을 지원하는 것은 아닙니다.
현재 코드와 합성 회귀에 근거한 [형식별 지원표와 실패 계약](FORMAT_SUPPORT.md)을 샘플 시험의 시작점으로 사용합니다. HEIC/JP2 등 합성 서명 실패 시험을 유효 업무 파일 호환성 인수로 바꾸지 않습니다.

| 대상 | 시험해야 할 변형 | 현재 경계 |
| --- | --- | --- |
| JPEG/PNG/GIF/BMP 및 WebP | EXIF 방향1~8, 투명도, ICC/색상, 정지/애니메이션, 손상/예산 초과 | JDK/실제 디코더별 지원을 확인. WebP 헤더 분류가 디코딩 성공을 보장하지 않음. 애니메이션 전체 재생도 별도 인수 |
| TIFF/TIF | 다중 페이지, 압축별·RGB/회색/팔레트/CMYK·방향·BigTIFF·대형 | 타일 승인 범위는 classic TIFF RGB8/3samples/방향1/비압축/contiguous만. 다른 입력의 미리보기 성공이 타일 지원을 뜻하지 않음 |
| HEIC/HEIF·JPEG2000 | 실제 컨테이너/브랜드·JP2/J2K·비트 깊이·방향/색상 | img2tile 지원 선언과 업무 샘플 인수는 별개. 검증 안 된 원본 좌표 편집은 계속 차단 |
| MP4/MPEG/MPG | 컨테이너+코덱 조합, 무음, VFR, 회전, 장시간·손상·탐색 | FFprobe 제한을 통과한 입력을 열람용 WebM으로 변환. 원본 보존·손실 변환 결과 구분 |
| MP3/WAV | PCM/압축 WAV·샘플율·채널·VBR·손상·재생 시간/탐색 | 지원 입력을 MP3 열람본으로 변환. 첫 오디오 트랙 선택 및 실제 음성/시간 확인 |
| 블랙박스·녹음기 | 실제 장비별 파일, 복수 영상/음성, GPS/암호화/제조사 부가 데이터 | 첫 일반 영상/첫 오디오만 선택. 멀티 카메라 선택·부가 데이터·암호화 전용 포맷은 미구현 범위로 표시 |

업무 파일·실행 파일·DLL·계정/토큰은 저장소에 넣지 않습니다. 표본은 접근 제한 저장소에서 관리하고 인수 기록에는 비식별 샘플 ID·기대 결과·관측 결과·허용된 증적 참조만 남깁니다. 메모/스탬프는 클릭 생성·이동·회전/확대 후 좌표·undo/redo·충돌·원본 버전 변경을 확인하고, crop/합성 PNG는 화면 축소본이 아닌 검증된 원본 좌표·픽셀을 대조합니다.

## 기존 도구 실행

개발 회귀 검증은 아래 명령입니다. 합성 시험 저장소를 사용하는 실제 모듈/브라우저 테스트이며 운영 인증 경로를 대신하지 않습니다. JDK21과 설치된 신뢰 모듈·브라우저/Node 환경은 각 도구 문서에 맞춰 지정합니다.

```powershell
.\gradlew.bat --no-daemon --console=plain build -Pimg2tileIntegration -PffmpegIntegration -PnativeViewerIntegration
```

일반 build는 선택 성능 실험을 실행하지 않습니다. 필요한 실험만 개별 실행하고 운영 목표와 별도로 해석합니다.

| 목적 | 실행 / 절차 | 설명 |
| --- | --- | --- |
| 실제 HTTP 기준선 | .\gradlew.bat httpPerformanceTest | [HTTP 측정](HTTP_PERFORMANCE.md), loopback/합성 인증 |
| 대형 TIFF·재생 혼합 | .\gradlew.bat mixedMediaPerformanceTest | [혼합 부하](MIXED_MEDIA_PERFORMANCE.md), native/합성 자료·자원 범위 확인 |
