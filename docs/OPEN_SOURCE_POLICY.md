# 오픈소스 사용 정책

- 상용 SDK, 비상업용·평가판·소스 공개 전용 제품, 유료 필수 플러그인은 사용하지 않습니다.
- MIT/BSD/Apache-2.0 등을 우선 검토합니다. LGPL은 연결·수정·배포 조건을 확인합니다.
- GPL/AGPL은 기본 선정에서 제외합니다. 외부 프로그램으로 실행하는 경우도 배포 의무 확인이 필요합니다.
- 직접·전이 의존성, 프런트엔드·폰트·아이콘, 실행 파일·DLL, 코덱을 모두 목록화합니다.
- 이름이 아닌 실제 버전·빌드·배포 파일을 기준으로 라이선스·저작권 고지·소스 제공 의무를 기록합니다.
- 최종 배포 전 SBOM, 취약점 확인, 필요한 고지·라이선스·소스 자료를 준비합니다.
- Gradle dependency locking으로 해석된 버전을 기록합니다. 잠금 파일은 라이선스/보안 검토를 대체하지 않습니다.
- 현재 Spring Boot/Spring Framework/Spring Security/Gradle의 대표 라이선스는 Apache-2.0이지만,
  전체 해석 의존성의 적합성 검토가 완료되었다는 의미는 아닙니다.
- img2tile은 사용자가 사용에 문제가 없음을 확인한 팀 내부 개발 프로그램으로 예외 승인된 구성요소입니다.
  내부 사용 검증을 진행하며 오픈소스라는 의미로 분류하지 않습니다. 프로젝트에는 바이너리를 포함하지 않습니다.
  제3자 DLL과 최종 배포물 고지는 기존 정책대로 관리합니다.
- ImageMagick은 초기 의존성 및 실행 경로에서 제외합니다.
- FFmpeg는 향후 GPL/nonfree 구성요소 없는 빌드를 우선 검토하고 외부 라이브러리도 확인합니다.
- 미디어 코덱의 특허 조건은 오픈소스 저작권 라이선스와 별도로 확인합니다.
- 프로젝트 자체의 공개·배포 라이선스는 아직 지정하지 않았습니다.

## FFmpeg 재생 모듈

외부 ProcessBuilder 방식으로만 사용하며 바이너리/DLL은 배포물에 포함하지 않습니다. 현재 검증본은 LGPL 3 이상 shared 빌드입니다. 실행 파일 해시·라이선스 고지·GPL/nonfree 미활성·필수 인코더·도구 버전 일치를 확인합니다. 이것은 모든 포함 라이브러리/재배포/코덱 특허 조건에 대한 법률 보증이 아닙니다. 공식 안내와 실제 버전·해시는 PLAYBACK.md에 기록했습니다. 프로젝트의 새 Java/브라우저 런타임 의존성은 추가하지 않았습니다.

## 실제 런타임 식별 기준선

config/oss/runtime-license-baseline.json은 현재 Java 런타임의 기술적 식별 근거와 해시를 관리합니다. verifyRuntimeLicenses를 check/build에 연결하며 자동 승인·기준선 자동 갱신을 제공하지 않습니다. 대표 조건만으로 내장 하위 라이선스를 덮어쓰지 않습니다. 실제 Logback 1.5.22 POM의 EPL-1.0 선언을 최신 홈페이지의 EPL-2.0으로 대체하지 않습니다. 내장 고지 없는 항목의 전문 보완·EPL 소스 이용 안내·JDK/외부 DLL·최종 SBOM/취약점·배포 명세는 계속 필요합니다. 상세 범위는 RUNTIME_LICENSES.md를 참고하세요.
