# 편집 PNG 합성 반출

## 구현한 화면

우측 편집 이미지 저장에서 전체 페이지 저장 또는 선택 영역 저장을 사용합니다.
다음 옵션을 각각 선택할 수 있습니다.

- 저장된 메모·스탬프 포함
- 현재 밝기 적용
- 현재 회전 적용

전체 페이지는 정방향 원본의 전체 영역을 사용합니다.
선택 영역은 자르기 도구의 정수 원본 영역을 사용하며 별도 자르기 권한도 요구합니다.
반출 PNG에는 선택 테두리·선택 강조·크기 조절 핸들·돋보기·도구 패널을 넣지 않습니다.
화면 밝기는 기본 이미지에만 적용하고 메모·스탬프는 그 위에 합성합니다.
마지막으로 선택한 현재 회전을 적용합니다. 90/270도는 출력 너비·높이가 바뀝니다.
원본·주석·스탬프 파일은 수정하지 않습니다. 결과는 다운로드 사본이며 새 mediaId로 등록하지 않습니다.

메모 내용의 미적용 초안이 있거나 주석을 저장 중일 때는 주석 포함 다운로드를 막고 적용을 안내합니다.
저장 요청 이후 바꾼 보기 옵션은 진행 중 요청에 소급 적용하지 않습니다.
파일/페이지 변경·세션 종료·권한 회수·페이지 종료 또는 진행 중 Esc는 다운로드를 취소하고 늦은 응답을 무시합니다.
편집 반출 버튼은 설치 정책, 파일 EXPORT_EDITED 권한, 원본 좌표 확인, 출력 픽셀 상한을 함께 반영합니다.

## API

POST /api/v1/media/{mediaId}/pages/{page}/export

~~~json
{
  "mediaVersion": "30000000-0000-4000-8000-000000000001",
  "coordinateSpaceId": "original:30000000-0000-4000-8000-000000000001:1:upright-v1",
  "x": 100,
  "y": 120,
  "width": 240,
  "height": 160,
  "expectedRevision": 7,
  "includeAnnotations": true,
  "brightness": 135,
  "rotation": 90
}
~~~

모든 필드는 필수이며 알 수 없는 필드는 거부합니다.
좌표·크기와 expectedRevision/brightness/rotation은 유한한 정수만 허용하고 분수를 자동 절삭하지 않습니다.
expectedRevision >= 0, brightness=25~200, rotation=0/90/180/270입니다.
회전을 적용하지 않으려면 0, 밝기 미적용은 100, 주석 미포함은 includeAnnotations=false를 보냅니다.
주석 미포함일 때 expectedRevision은 0을 보낼 수 있으며 주석 저장소를 읽지 않습니다.
영역은 정방향 원본 안에 있어야 합니다. 전체 페이지 요청은 x/y=0과 페이지 원본 너비/높이를 사용합니다.

신뢰된 ViewerPrincipal·CSRF와 최신 파일 VIEW/EXPORT_EDITED 권한을 확인합니다.
전체 원본보다 작은 영역을 요청하면 CROP_AND_SAVE 권한과 crop-and-save 설치 정책도 확인합니다.
수정 권한 ANNOTATE/STAMP와 반출 권한은 별개입니다.
저장된 스탬프는 파일 권한에 따라 합성할 수 있으며 업로더 개인 라이브러리에 접근 권한을 부여하지 않습니다.
밝기/회전 설치 정책이 꺼져 있으면 각각 100/0 이외 요청은 403으로 거부합니다.

성공 응답은 200 image/png, Cache-Control: no-store,
Content-Disposition: attachment; filename="imagegate-edited-p1.png"입니다.
Content-Length, X-Image-Width, X-Image-Height는 최종 회전 결과에 맞게 제공합니다.
브라우저는 반환 MIME·바이트 상한·실제 PNG 해상도를 확인한 후 다운로드합니다.

오류는 CROP_EXPORT.md의 입력/원본/크기/동시성/권한 오류를 따릅니다.
추가로 주석 revision 충돌도 EDIT_CONFLICT(409)입니다.
렌더링 글꼴이 메모 문자를 지원하지 않으면 EXPORT_FONT_UNAVAILABLE(422)로 거부합니다.
내부 경로·스탬프 소유자·명령어·원본 내용은 응답하지 않습니다.

## 서버 신뢰 경계와 합성 규칙

클라이언트가 보낸 메모 텍스트·주석 배열·스탬프 경로/URL을 합성 입력으로 받지 않습니다.
버전/페이지/원본 좌표계와 일치하는 서버 주석 스냅샷을 읽고 expectedRevision을 검사합니다.
설치에서 비활성화한 메모/스탬프 유형은 기존 조회 정책과 동일하게 제외합니다.
두 유형 모두 비활성인 상태에서 주석 포함을 요청하면 403입니다.

원본 SHA-256·디코더 크기·EXIF 방향을 다시 검증하고 기존 원본 해상도 자르기 경로를 사용합니다.
밝기는 RGBA의 알파를 보존하며 기본 이미지 RGB에 적용합니다.
그 위에 저장 순서대로 주석을 합성하며 영역 밖 항목은 디코딩 없이 건너뜁니다.
스탬프는 서버가 PNG로 정규화해 보관한 전체 크기 이미지(최대 2048px·4,194,304픽셀)를 사용합니다.
256px 브라우저 미리보기를 확대해 반출하지 않습니다.
한 번에 스탬프 하나씩 디코딩·합성·해제하며 이미지 크기와 PNG 디코더를 다시 확인합니다.
메모는 HTML 처리 없이 문자로 렌더링하고 영역 안에서 줄바꿈·잘라내기를 적용합니다.
원본에 좌표를 적용해 메모/스탬프를 합성한 다음 출력 회전을 적용합니다.

합성 완료 후 전송 직전에 파일 권한·원본 버전·주석 revision을 다시 확인합니다.
작업 중 저장된 주석이 바뀌면 완성 PNG를 내려받지 않고 409를 반환합니다.
이 검사는 전송 직전 스냅샷을 보장하며 이미 전송된 바이트를 회수하는 기능은 아닙니다.

## 상한·저장·글꼴

imagegate.features.image.export-edited로 설치 시 사용 여부를 선택합니다.
이미지 전체 기능이 꺼져 있으면 반출도 비활성입니다.
기존 imagegate.crop의 원본/출력 픽셀·출력 바이트·동시 처리 상한을 자르기와 편집 반출이 공유합니다.
설정 키를 중복해 같은 서버에서 독립적으로 과도한 합성 작업을 허용하지 않습니다.
기본 원본 16,000,000픽셀, 출력 8,000,000픽셀·16MiB, 동시 저장/전송 1개입니다.
원본 전체가 출력 상한보다 크면 작은 영역을 선택해야 합니다.
회전 시 추가 출력 래스터가 필요할 수 있으므로 픽셀 상한과 JVM 메모리를 함께 고려해야 합니다.
다운로드가 끝날 때까지 공유 슬롯을 유지하고 전송/합성 예외에서도 반환합니다.

임시 PNG는 기존 converted-directory/crop-work-v1의 작업별 폴더에 만들고 정상 완료/실패 시 정리합니다.
파일/PNG 전체를 HTTP byte[] 응답에 넣지 않습니다.
강제 종료·OS 파일 잠금의 잔여 작업 정리는 기존 자르기 운영 지침을 따릅니다.

글꼴 파일·웹폰트·새 런타임 라이브러리를 포함하지 않았습니다.
JDK 논리 글꼴 SansSerif와 서버에 설치된 글꼴의 대체 기능을 사용합니다.
메모에 사용하는 언어를 지원하는 글꼴이 서버에 필요합니다.
지원하지 않는 글자를 대체 상자로 저장하지 않고 422로 알립니다.
서버와 브라우저의 글꼴·렌더러 차이 때문에 글자 폭·줄바꿈·안티앨리어싱이 완전히 같지는 않습니다.
노트의 원본 좌표·크기·배경/테두리·글자 크기 규칙은 유지합니다.
서버 반출은 저장 순서를 사용하며 브라우저의 일시적인 선택 강조나 그림자는 합성하지 않습니다.

## 검증과 잔여 범위

Java: 밝기의 RGB/알파·스탬프 투명도·메모 문자/클리핑·4방향 출력 회전,
저장된 주석 기반 합성·서버 스탬프 조회·공유 파일/개인 라이브러리 격리,
분수/누락/본문 상한·CSRF·반출/자르기 권한 분리·설치 정책,
합성 중 주석 revision 변경·전송 직전 권한 회수·임시 파일/슬롯 정리를 검사합니다.

브라우저: 미적용 초안 보호, 전체/선택 영역 다운로드, 주석 revision과 밝기/회전 옵션,
409 안내, MIME 거부, 페이지 전환 중 취소, 읽기 전용 차단을 검사합니다.
브라우저는 실제 UI와 합성 API/PNG를 사용하며 실제 서버 합성 픽셀은 Java 테스트로 별도 확인합니다.
실제 SSO 종단간·업무 자료 P95/동시 부하·조직 할당량·감사 이력·업무 사본 등록·실행 취소/다시 실행은 잔여 작업입니다.
설치 ZIP은 최종 배포 검증 이후에만 생성합니다.
