시안 설명

세 시안 공통 변경

  • 토큰 적용: 최소 12px 글자, 4px 간격, 역할 이름 색, 라이트 테마의 로고·배지 색 수정(U7·U16·A3)
  • 유니코드 문자 대신 SVG 아이콘, 모든 아이콘 버튼에 이름과 툴팁(U3)
  • 버튼 위계: 기본(편집본 저장)·보조·텍스트·위험 4단계(U8)
  • 동영상·음성에서는 이미지 전용 헤더 도구를 숨김(U9)
  • 안내는 화면을 가리지 않는 알림으로, 전체 화면 오류는 파일 표시 실패에만(U13·U10)
  • 저장 완료 알림(U2), 앱 안 삭제 확인 창(U6), 단축키 도움말(U14·U17), 빈 화면 끌어다 놓기 영역(U17)
  • 모바일: 아래 탭 막대와 시트로 패널을 열어 이미지를 가리지 않음(M1)
