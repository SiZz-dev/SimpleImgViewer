# 레이아웃 시안 비교 (리뉴얼 3단계)

2026-11-19. 1단계 점검([UX_HEURISTIC_REVIEW.md](UX_HEURISTIC_REVIEW.md))의 레이아웃 항목(U15·U8·U9·U3·U4·M1, 빈 화면)을, 2단계 토큰([UX_DESIGN_TOKENS.md](UX_DESIGN_TOKENS.md))으로 그린 시안 세 개로 비교합니다. **이 문서는 선택을 돕기 위한 것이며, 실제 화면 코드는 고른 뒤 4단계에서 바꿉니다.**

## 1. 시안 보는 곳

- 클릭 가능한 시안(claude.ai 비공개 페이지): https://claude.ai/artifact/1ZPEY5uGrH6yPqCCo1oQcr
- 같은 시안의 저장소 사본: [prototypes/viewer-layouts.html](prototypes/viewer-layouts.html). 브라우저로 바로 열 수 있고, 외부 리소스 없이 혼자 동작합니다.
- 시안 화면에서 바꿔 볼 수 있는 것
  - 시안 A·B·C, 제품 테마(다크·라이트), 기본 글자 13·14px
  - 데스크톱 1440×900·모바일 375×812
  - 화면 상태: 이미지 편집·동영상·음성·빈 화면
- 직접 눌러 볼 수 있는 것: 파일 행(화면 전환), 삭제 아이콘(앱 안 확인 창), 저장 버튼(완료 알림), 스탬프 도구(스탬프를 고르지 않았을 때의 안내 알림), 도움말 아이콘(단축키 목록), 접이식 섹션·탭·도구 막대

## 2. 세 시안

| 시안 | 도구 패널 구조 | 저장 버튼 위치 |
| --- | --- | --- |
| **A 접이식 섹션** | 지금 구조를 유지하고 섹션을 접고 펼침. "메모·스탬프"와 "자르기·저장"은 펼침, "보기 조정"과 "파일 정보"는 접음 | 둘째 섹션 안 |
| **B 탭** | 편집·내보내기·보기·정보 네 탭 | "내보내기" 탭 안 |
| **C 도구 막대 + 고정 저장** | 이동·메모·스탬프·자르기를 이미지 위 떠 있는 막대로 옮기고, 오른쪽 패널은 선택 항목의 속성만 보여 줌 | 패널 아래에 항상 고정 |

**세 시안 공통 변경**
- 토큰 적용(최소 12px, 4px 간격, 역할 이름 색, 라이트 테마 로고·배지 수정)
- SVG 아이콘으로 통일
- 버튼 4단계(기본·보조·텍스트·위험)
- 동영상·음성에서는 이미지 전용 헤더 도구를 숨김
- 안내는 화면을 가리지 않는 알림으로, 저장 완료 알림, 앱 안 삭제 확인 창
- 단축키 도움말, 빈 화면 끌어다 놓기 영역과 지원 형식·크기 안내
- 모바일은 아래 메뉴 막대와 시트로 패널을 열어 이미지를 가리지 않음

## 3. 측정 결과

시안 페이지가 각 시안을 실제 크기로 그린 뒤 스크립트로 측정했습니다.

| 기준 | A | B | C |
| --- | --- | --- | --- |
| 편집본 저장 버튼 · 1440×900 · 13px | 스크롤 없이 보임 | 탭 이동 필요 | 항상 보임(고정) |
| 같은 조건 · 14px | 스크롤 없이 보임 | 탭 이동 필요 | 항상 보임(고정) |
| A에서 모든 섹션을 펼친 최악의 경우(14px) | 스크롤 없이 보임 | — | — |
| 패널 내용 높이 / 보이는 높이(13px, 기본 상태) | 828px / 777px | 탭마다 짧음 | 속성 스크롤 + 저장 고정 |
| 이미지를 연 직후 편집본 저장까지 클릭 | 1 | 2 | 1 |
| 자르기 저장까지 클릭(드래그 제외) | 2 | 3 | 2 |
| 모바일 저장 | 아래 막대의 "저장" 시트. "편집 도구" 시트 안에서는 스크롤 필요 | 아래 막대의 "저장" 시트 | "속성" 시트 아래에 고정 |

- **현재 화면과 비교:** 지금은 1440×900에서 저장 버튼이 917px 위치에 있어 화면 밖입니다. 세 시안 모두 이 문제(U15)를 해결합니다.
- **확인한 범위:** 3 시안 × 2 테마 × 2 글자 크기 × 2 화면 × 4 상태와 모바일 시트별 상태까지, 모두 188개 화면을 그려 점검했습니다.
  - 글자가 상자를 넘치는 곳 0
  - 시안 밖으로 삐져나간 요소 0
  - 24px보다 작은 클릭 대상 0
  - 콘솔 오류 0
  - 시안 페이지 자체도 폭 420px에서 가로 스크롤이 생기지 않음

## 4. 추천

**C를 추천합니다.**
- 저장 버튼이 패널 길이나 글자 크기와 상관없이 항상 보입니다. 글자를 12px 이상으로 키워도 U15가 다시 생기지 않습니다.
- 도구를 바꿀 때 오른쪽 패널까지 갈 필요가 없어, 메모·스탬프·자르기를 오가는 작업이 가장 짧습니다.
- 모바일에서도 같은 막대를 쓰므로 데스크톱과 사용법이 같습니다.
- 단점: 바꾸는 범위가 가장 큽니다(도구 막대를 새로 만들고, 패널 역할이 바뀜). 막대가 이미지 윗부분을 조금 가립니다. 4단계에서 이미지 맞춤 계산에 막대 높이를 빼서 가리지 않게 합니다(시안에도 반영).

**대안:** 변경 위험을 최소로 하고 싶다면 **A**입니다. 측정상 저장 버튼 문제는 A로도 해결되고, 현재 `ToolsPanel`에 섹션 접기만 넣으면 됩니다. 다만 앞으로 도구가 늘면 다시 길어질 수 있습니다.

**B는 추천하지 않습니다.** 가장 자주 쓰는 결과 동작인 저장이 탭 뒤로 숨어, 클릭이 늘고 처음 쓰는 사람이 찾기 어렵습니다.

## 5. 결정 (2026-11-19)

- 도구 패널 구조: **C** 선택(사용자 결정)
- 기본 글자 크기 13px, 시스템 글꼴 유지(별도 요청 없음 → 기본안)

### 결정 전 선택지

1. 도구 패널 구조: **C**(추천) / A / B
2. 기본 글자 크기: 13px / 14px. 세 시안 모두 두 크기에서 저장 버튼 문제가 없으므로 읽기 편한 쪽을 고르면 됩니다.
3. 글꼴
   - 시스템 글꼴 유지(시안과 같음, 추가 내려받기 없음)
   - Pretendard 같은 한글 글꼴 직접 제공(일관성은 좋아지지만 첫 화면 내려받기와 라이선스 고지 추가)

## 6. 4단계로 넘길 메모

- 반영 순서: 토큰 → 아이콘 → 레이아웃(선택한 시안) → 동작 변경
  - 동작 변경: U13 알림 분리, U14 단축키·드롭·핀치, A1 키보드, U6 삭제 확인 창 등
- 시안의 아이콘은 이 작업을 위해 직접 그린 단순 SVG입니다. 4단계에서는 라이선스가 분명한 오픈소스 세트(예: ISC 라이선스 아이콘)로 바꾸거나, 이 SVG를 `components/icons`로 옮겨 씁니다.
- 시안 모바일 화면의 메모 글자는 이미지 확대 비율에 따라 작아집니다. 실제 앱은 화면 전체를 함께 확대·축소하므로 이와 같습니다.
- 시안 페이지의 바깥 부분(설정 막대·표)은 비교용 도구일 뿐 제품 디자인이 아닙니다.
