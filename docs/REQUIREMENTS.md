# 확정 요구사항

## 최우선 기준

- 뷰잉 속도와 보안. 최초 표시·파일 전환·확대 반응의 P50/P95를 실제 샘플과 동시 사용자 조건으로 측정.
- 원본 보존, 화면용 변환본 재사용, 페이지 지연 로딩, 대형 이미지의 타일 제공.
- 원본·미리보기·썸네일·타일·스탬프·어노테이션 모두 파일/업무 건별 접근 검사.
- 원본·변환본의 버전과 방향 보정 좌표계 연결. 편집 결과는 서버에서 검증해 사본 생성.

## 지원 대상

현재 코드/합성 회귀에 근거한 범위는 [형식별 지원표](FORMAT_SUPPORT.md)를 참고합니다. 아래 목표 형식 목록은 모든 코덱/압축/색상 변형의 인수 완료를 뜻하지 않습니다.

- 이미지: 다양한 형식을 목표로 하되 형식·압축·페이지·색상별 실제 지원표 관리.
- img2tile: TIFF/TIF, HEIC, JPEG 2000 → PNG/JPG. 사용자 제공 지원 범위이며 로컬 검증 예정.
- 영상: MP4, MPEG/MPG. 음성: MP3, WAV. 확장자뿐 아니라 내부 코덱 확인.
- ImageMagick 초기 제외. 필요 시 검토 후 어댑터 추가 가능.
- 외부 상용 SDK·유료 필수 기능 제외. 오픈소스·코덱·DLL의 실제 배포 조건 확인.

## 화면

- 다크 기본, 헤더 버튼 하나로 라이트 전환. 선택 저장. 미디어 색상·저장 결과에는 테마 미적용.
- 헤더는 한 줄, 푸터 없음. 폭이 부족하면 보조 도구를 더보기로 이동.
- 좌측 썸네일·파일 목록, 접기·펼치기. 중앙 열람 공간 확장.
- 우측 밝기·어노테이션·스탬프와 도구별 속성 배치.
- 영상·음성의 seek bar와 현재/전체 시간은 중앙 플레이어 내부에 배치.

## 이미지 도구

- 회전, 확대·축소, 화면 맞춤·100%, 선택 영역 자르기·별도 저장, 밝기, 돋보기.
- 메모·스탬프 선택 후 이미지 위 마우스 클릭 위치에 생성. Esc로 배치 모드 해제.
- 스탬프는 사용자가 이미지 업로드. 형식·실제 파일·크기·픽셀·권한 검증 후 사용.
- 메모·스탬프 이동·수정·삭제, 스탬프 크기·회전·투명도, 실행 취소·다시 실행.
- 페이지·원본 버전별 원본 좌표로 저장. 화면 축소본을 최종 자르기 원본으로 사용하지 않음.

## API 방향

- 파일 등록 API와 뷰어 세션 생성 API 분리. mediaIds와 초기 페이지/시간으로 열기.
- 인증 정보는 신뢰 가능한 인증 계층에서 확정. 호출자가 전달한 권한·사용자 ID를 신뢰하지 않음.
- 미디어 정보: ID, 원본 버전, 실제 형식, 상태, 서버 계산 권한, 표시용 소스.
- 이미지: 페이지 수, 페이지별 방향 보정 좌표계·크기. 영상·음성: 재생시간·탐색 가능 구간.
- 변환 중에는 statusUrl을 통해 제한된 주기로 상태 확인. 바이너리는 JSON Base64 대신 별도 응답.
- 같은 출처의 인증된 미디어 API 우선, 영상·음성 HTTP Range 및 만료 후 처리 검증.
